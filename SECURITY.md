# Security policy

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub security advisories](https://github.com/octrow/pycommons/security/advisories/new).
You should get a reply within a week.

## Supported versions

Only the latest release gets fixes.

## Scope

In scope: problems in this library's code, for example a race or data loss in the atomic JSON store, or secrets leaking through logging or env loading.
